## 真实安装扩展的 E2E

测试直接加载 `.output/chrome-mv3`，使用真正的 MV3 worker、扩展 origin、IndexedDB、chrome.storage、scripting 和标签页 API；没有把普通 React 网站伪装成扩展。测试网页来自回环 HTTP 服务器。

1. **完整闭环**：创建「理解参数方程」；工具栏真实 action 授权后获取当前网页，在 UI 确认保存；另手动保存第二个测试资料页。使用实际注入脚本提取普通正文选区，再经临时捕获草稿和 UI 合并保存。填写三段现场、暂停、关闭并重开界面、完全退出并重启测试浏览器，核对持久数据。快速连续点击接着做仅打开选中资料一次，不改动无关标签页；创建第二任务、独立暂存、搜索、实际下载 JSON、损坏导入保留原数据、新资料目录导入并核对引用、已有数据旁再次导入、英文及离线操作。停止并重新唤醒 MV3 worker 后继续主流程。默认功能未观察到扩展自身外发请求；打开资料页属于预期浏览。
2. **真实权限降级**：无授权时拒绝捕获；原生 action 授权后可读取。真实页面可编辑区域选区被拒绝；跨站导航后权限失效；`chrome://version` 被拒绝；非法消息被拒绝。
3. **布局及键盘**：320 / 360 / 420 / 480 px 侧栏布局、1024 / 1440 px 全页面；CSS 200% 布局放大无横向溢出；模态框 Esc 退出、焦点恢复。CSS 放大不能替代 Chrome 菜单原生缩放和屏幕阅读器人工检查。
4. **真正的原生侧边栏**：通过浏览器级 CDP `Extensions.triggerAction` 触发实际扩展工具栏 action，验证 activeTab 授权；附加到浏览器创建的侧边栏 WebContents，在该容器内操作实际按钮完成网页保存，核对数据库 URL。截图 `11-native-side-panel.png` 来自这个原生容器。没有直接伪造 onClicked 事件或授予权限。浏览器自动化只使用其扩展调试开关，不关闭网页安全策略。
5. **数据控制及模型失败**：示例与用户任务隔离；追踪参数清理、敏感参数明确选择、撤销、用途编辑、快照资源引用清理、完成与重开、归档和永久删除。用合成配置模拟「已启用但未授予本地主机权限」，真实提供器返回权限失败并保留原数据和本地规则，无外发；随后关闭并清理。这不代表测试过实际权限对话框或已运行 Ollama。
6. **跨窗口删除**：一个扩展窗口移除资料，另一个正在编辑该资料的窗口关闭旧编辑框；通过真实 session 事件给两窗口显示合成的待保存捕获，一个窗口删除全部数据，另一个的捕获文本、队列和弹窗随之消失。重新创建任务并打开添加资料时内容为空，数据库没有旧资料复活。

选区 E2E 覆盖真实捕获脚本和保存链路，但选区草稿入队由测试驱动，未冒充操作系统右键点击。系统右键入口另有处理器契约测试和下列手工步骤。

## 实际发现并修复的问题

- **工具栏打开不等于授权**：`openPanelOnActionClick: true` 的 Chromium 路径未授予 activeTab。改为普通 action 监听器同步调用 `sidePanel.open()`，安装及启动时关闭内置自动打开行为。真实授权及原生侧边栏测试均通过。
- **草稿并发及重复操作**：修复已提交 revision 尚未被 live query 反映时立即暂停的冲突；提供明确外部修改冲突处理；阻止快速重复恢复、保存和提交。失败不显示已保存。
- **捕获归属竞态**：捕获开始时记录目标任务，在入库事务中重新核对；另一窗口切换任务时保留待归属草稿，不悄悄存到错误任务。
- **删除与界面状态**：删除资源同时处理快照引用、撤销及旧模型建议；修复设置/任务页面刷新后路由退回旧位置的问题。
- **最后的并发与隐私边界**：整页 `designMode` 编辑器选区拒绝捕获；不同资料打开请求分别去重，不吞掉第二个请求。清空数据通过无内容代号同步各窗口的内存草稿，清理资料编辑框和导入预览；捕获最终提交与清空通过共享 Web Lock 排序，并拒绝清空之前开始、之后才返回的旧捕获。
- **浏览器运行时**：缓存 Chromium 在本机以 Windows 14001 / SideBySide 事件 33 启动失败。将官方 Playwright 配套文件原样复制到项目独立目录后可用，关键文件 SHA-256 相同。没有修改用户浏览器、全局缓存或系统安全设置。精确的缓存路径程序集解析原因未确定，诊断证据在 `artifacts/browser-runtime-diagnostic.json`。

## 未验收范围与准确手工步骤

- **物理工具栏/系统右键/快捷键**：浏览器原生 action 已通过 CDP 执行；没有真人鼠标点击工具栏。Playwright 的网页键盘注入没有触发浏览器扩展快捷键，因此不记为快捷键通过。在普通测试网页点击工具栏，确认只打开面板；右键页面及普通正文选区分别保存，检查归属、URL、摘录；在输入框/密码框/跨表单选区重复操作，应拒绝捕获。打开 `chrome://extensions/shortcuts` 核对绑定后，实际按 Ctrl+Shift+Y 和 Alt+Shift+S，确认打开/保存且没有重复入库。
- **可选权限对话框及真实 Ollama 推理未验收**：没有下载模型、改环境变量或服务。按隐私文档自行配置已安装的本地模型后，主动开启，检查授权仅为回环地址；拒绝权限应仍可完成普通流程。连接测试应列出实际模型，预览后整理，建议需明确采用才更新下一步。停服务、取消、关闭开关均应回到本地规则；关闭后检查权限撤销。真实生成质量与本地服务是否再联网需另行核实。
- **Edge、Chrome 116 实机**未测试；Chrome 最低版本来自 API 要求，实际自动化仅上述 Chromium 153。Firefox/Safari/手机未实现。
- **真人无障碍及用户效果**未验收：在 Chrome 菜单设置 200% 缩放，键盘走完创建、记录、暂停、恢复、导入；用屏幕阅读器听读标签、错误和保存反馈。尚无真实用户研究、恢复时间改善或医学疗效数据。
