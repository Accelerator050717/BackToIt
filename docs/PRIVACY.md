# 隐私与数据控制

默认模式下扩展本身不发送网络请求，不提供账号、不遥测、不请求第三方字体或 favicon。打开你选择的资源链接是正常浏览，目标网站遵循其自己的隐私政策。

## 保存什么

只保存你创建的任务、填写的进度/卡点/下一步，以及主动保存的网页标题、HTTP(S) 链接、普通正文摘录、用途备注、保存时间、所属任务。快照保留当时文字字段和资源 ID。暂存想法独立存放。不索取诊断或健康资料。

不获取全页正文、浏览历史、Cookie、登录凭据、输入框、密码框、表单或可编辑区域，不常驻监听键盘/剪贴板。没有全站 content script。正文摘录最多 12,000 字符，过长会截断并提示。页面捕获需要当次有效的 activeTab 权限，受保护页面无法读取。

只接受 HTTP(S) 链接，去掉嵌入的用户名密码及明确追踪参数，保留普通查询和锚点。疑似 token、授权码或签名参数由你决定去掉还是保留；保留后会进入本地备份。不执行用户或模型提供的 HTML。

## 存储、备份和删除

任务内容保存在扩展自身的 IndexedDB，设置在 chrome.storage.local；未归属的捕获草稿暂放 chrome.storage.session，浏览器重启可能丢失，界面不将这种草稿描述成已入库。没有云端副本。

本地存储不是加密保险箱。持有本机浏览器资料访问权的人可能读取它。JSON / Markdown 导出也是明文。卸载扩展、删除浏览器资料或换电脑可能使内容不可用，请主动备份。

JSON 备份不含模型连接设置或密钥；本版没有密钥字段。导入只创建新任务，不替换现有任务。严格校验和整体事务失败时保留现有数据。导入文件最多 5 MiB，内容总配额 4 MiB；条目上限为 500 任务、5000 资源、5000 快照和 2000 暂存项。

删除资料会删除其摘录、撤销副本以及快照中的引用；删除任务级联删除关联内容。模型建议仅放在当前界面内存中，内容改变后标记过期，资源删除后清除有关建议。清理示例只影响带示例标记的任务。删除全部内容需要明确确认；导出的外部备份文件需要你自行管理。本扩展不能替你删除外部备份或声称远程删除不存在的上传记录。

## 为什么需要权限

| 权限         | 用途                                     |
| ------------ | ---------------------------------------- |
| storage      | 少量本地设置及临时会话草稿               |
| activeTab    | 用户工具栏/命令/右键操作后临时读取当前页 |
| scripting    | 显式保存时执行一次性、限定范围的捕获     |
| contextMenus | 页面及正文选择的保存菜单                 |
| sidePanel    | 日常操作侧边栏                           |

无 tabs/history/cookies/webRequest 权限、全站主机权限、常驻网页脚本或隐身采集。只有确认可见 URL 完全相同时才复用标签页；无法验证时新开，不检查全局历史。

## 可选 Ollama

默认关闭；打开应用不探测服务。仅可连接 `http://127.0.0.1:11434` 或 `http://localhost:11434`，启用时才申请相应可选主机权限。Chrome 主机匹配规则不能限制端口，因此应用代码及 CSP 另行固定 11434，限制 API 路径，并拒绝重定向。关闭入口撤销可选权限。

连接测试查询已安装本地模型，不安装/拉取模型。v0.1 的兼容范围为具备本地权重和元数据的 GGUF completion 模型；拒绝云模型标记与远程模型元数据。整理前可查看实际发送的输入：仅当前任务的已保存字段、资源标题、笔记和摘录，不含完整 URL、其他任务、暂存想法、未主动保存的正文。预览最多 8 项当前任务资源，每项最多 2 段摘录，长字段截短，整体最多 20,000 字符。实际请求与预览一致，不发送预览之外的内容；正文内的完整链接也会遮去。

只有点击「帮我整理一下」后才发起推理。资料作为不可信文本，与系统规则分开；没有工具、自动浏览、脚本执行或其他数据读取能力。输出通过 Zod 校验长度、结构及当前输入 ID，链接由应用映射。建议仍可能不准确，需你核对后采用；不会自动变成完成事实。超时、取消、非法输出、失联或关闭时回到本地规则，任务内容保留。

**请求发给本机不代表该服务不会再联网。** 开启前请核对自己的 Ollama 服务配置，不使用云模型。扩展不更改你的服务或环境变量。根据 [Ollama 官方 FAQ](https://docs.ollama.com/faq)，可以二选一关闭其云功能：

```json
{ "disable_ollama_cloud": true }
```

放入你自行管理的 `%USERPROFILE%\.ollama\server.json`，合并已有配置而不要覆盖；或由你设置用户环境变量 `OLLAMA_NO_CLOUD=1`。重启 Ollama 并在其日志核对 `Ollama cloud disabled: true`。

若 CORS 拒绝本扩展，先从 `chrome://extensions` 复制本扩展 ID，将 Ollama 的 `OLLAMA_ORIGINS` 设置为**仅本扩展**的 `chrome-extension://你的扩展ID`，然后重启服务。设置页也显示实际扩展 origin。不要设为 `*` 或允许所有扩展；保持服务绑定在回环地址，不公开到局域网/互联网。不要关闭 Chrome 安全策略。移动已解压目录可能改变扩展 ID，需要重新核对 origin。

真实模型推理是否完成验收，请查 [TEST_REPORT.md](TEST_REPORT.md)，不要将适配器契约测试当成真实生成证据。
