# 产品与设计取舍

## v0.1 要解决的事

用户回来时能找到自己保存的「在做什么、做到哪里、卡在哪里、下一步做什么、相关资料在哪里」。这是一项产品假设，尚未通过真实用户研究验证；不宣称降低 ADHD 症状或产生医学疗效。

主流程：创建任务 → 主动保存网页/摘录/笔记 → 写可选现场草稿 → 保存并暂停 → 重新打开恢复卡 → 选择资料并接着做。没有记录时明确显示缺失或确定性的本地建议，不推断网页浏览就是学习完成。

## 取舍

- 以 360–420px 侧边栏为主要工作表面。全页面提供任务浏览、历史、设置与备份，不建立独立服务。
- 任一时刻只有一个当前任务。启动另一件事事务化暂停旧任务，不显示惩罚性提示。
- 草稿自动写入，有等待、已保存、失败及冲突状态；快照保存当时字段和资源引用，不存网页副本。关闭前只有明确完成的写入能够保证恢复。
- 首要资料默认打开一项；其他资料需用户选择。正常浏览由用户发起，不后台自动收集浏览行为。
- 输入框、表单、可编辑内容不作为正文摘录；侧边栏按钮不能自行取得新标签页权限。
- 同任务精确匹配清理后的 URL，保留非追踪查询和锚点，避免错误合并。
- 突然想到的事独立暂存。无提醒、逾期颜色、打卡、评分或强制专注。
- 内容备份按「作为新任务导入」重映射 ID；不覆盖现有数据，不做智能合并。
- 默认简体中文，提供完整英文；不翻译用户自己写下的内容。
- AI 只给建议，保留原始记录；无模型完全可用。AI 不是完成事实的证据。

视觉采用偏白和雾蓝、深色正文、小面积蓝色主要动作。本地系统字体与本地标识，单一下一步突出，剩余操作逐步展开。参考 `IMPLEMENTATION.md` 中设计标记。

## 明确不做

账号、云同步、支付、移动 App、协作、日历、番茄钟、奖励体系、拦截网站、诊疗、全量历史分析、屏幕录制、邮件/聊天集成。不能恢复未提交表单、光标、任意滚动位置或桌面布局。

## 已验证与未验证

工程行为以 [TEST_REPORT.md](TEST_REPORT.md) 为准。合成数据测试只能证明其中覆盖的程序行为，不能证明真实使用者的体验改善；恢复成本和记录负担仍需要用户验证，方案在 [DEMO.md](DEMO.md)。
