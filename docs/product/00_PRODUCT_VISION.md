# BackToIt v0.2 产品一页纸

日期：2026-10-22（America/Los_Angeles）。状态：发现阶段完成后的产品建议，尚未经真实用户验证或批准发布。

**建议：先验证一个用户主动开启、绑定已保存下一步的有限休息入口；默认候选为低刺激留白休息，把无内容返回作为重要对照。娱乐互动只用于比较，不进入正式扩展候选，直到它证明没有增加停留负担。**

## 为谁、在什么时刻

优先服务在电脑上学习或工作的成年人：已经知道自己想做什么，仍会在枯燥或疲惫时想暂时离开。是否有 ADHD 诊断不作为使用或招募条件。用户提供的朋友情境是需求线索，尚非访谈发现；不同人的休息动机不能合并成一种“ADHD 用户画像”。

当我想暂时离开学习时，我想有一个容易结束的停顿，并保留回来要做的具体动作，让返回少一次重新梳理。另一条同等重要的工作是：已经离开后，我仍能直接用原有 Resume 找回任务，不必补做休息流程。

## 核心价值与定位

主产品仍是「接着做」：任务 → 用户保存的下一步 → 需要的资料。辅助入口工作名为「歇一下 / Take a moment」，内部代号 Detour；采用日常动词避免把“分心”当成用户身份。原有「先放这里 / Parking」继续容纳临时想法，休息不另建任务系统。

与网站屏蔽、番茄钟和内容流的差异是用户保留决定权、休息存在终点、返回指向同一任务；这些是设计选择，尚未证明优于竞品。长期边界是帮助返回现实任务，不能以更久停留或更频繁打开为成功。

## 本轮范围与证据边界

- 交付研究、可验收 PRD、决策记录、独立本地原型和工程验证。
- 原型中的 C 留白休息、B 单轮轻互动和 D 无内容返回可比较；全部任务标为演示样例。
- 不合并 v0.1，不升级 schema，不新增权限，不发布版本。无账号、模型、内容推荐、遥测、手机检测或跨设备同步。
- 桌面扩展无权知道用户是否正在刷手机，也不能控制手机 App。当前没有证明休息入口会替代抖音/B 站的使用。

## 如何决定值得继续

先请 5–8 名自愿成年参与者完成探索性测试，人数是计划。看他们能否解释返回的下一步、是否感到被催促、是否反复延长，以及直接 Resume 是否已经足够。点击接着做只记为返回意图代理，不记成真正开始学习。
