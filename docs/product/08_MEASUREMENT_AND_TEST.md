# 测量定义、10–15分钟试用脚本与观察表

日期：2026-10-22。**当前真实参与人数为0；本文为可执行计划，没有A/B测试结果。** 自动化测试只验证工程行为。

## 两条路径与对照

路径1：样例任务 → 自述想离开 → 主动选择C/B/D → 明确结束 → 选择返回。路径2：样例任务 → 直接离开（不用Detour）→ 用原有Resume语义找回下一步。任何参与者都可选择第二条，不因没开Detour被排除。

C/B在同一人、同一任务下一步下比较；一半先C、一半先B，人数为奇数时记录顺序，不伪装随机平衡。时长统一选45秒以控制最大时长；B三步可提前自然结束，实际耗时不同需单独记录，不能把差异直接归因于形式。90秒只是默认产品假设，180秒仅测试延长/边界，不拿10分钟可用性测试寻找最佳时长。

## 指标的精确定义

“有效会话”指自愿开始、绑定存在的样例任务、工程未报错的一次体验；同一人每方案只取首次有效会话作主要对比，其余作为探索/保护记录。工程失败单列，不静默从报告消失。D的t0为显式结束岔路口、进入返回卡的时刻；直接Resume对照的t0为中断后返回卡首次可见的时刻。D/直接Resume没有休息时长，不能比较成同一剂量的休息实验。

Gate1的参与者分母N包含所有已同意记录、完成基线且没有阻断性工程故障的人；只选直接Resume、拒绝所有Detour或中途自愿退出者仍计入N，缺失结果另列。要求N至少5，并对全部N判断80%/60%阈值，不挑首批或最佳5人；技术故障人数和全部同意/退出人数也必须同时报告。

## 最低数据方案：默认不追踪

原型默认不记事件流水、不发送请求；只为演示恢复保存独立样例状态和会话时间戳。主持人经同意在本机填写匿名表，不记录姓名、诊断、账号、私密URL或任务正文。默认不录音/录屏。若同意记录更详细动作，先列清目的、字段、保存本机、7天删除及随时撤回；不参加数据记录也可体验。

匿名参与ID由主持人分配；测试样例统一使用“理解参数方程”。每人数据分开保存、原型重置后再交给下一位。不上传研究表到GitHub，不把外部备份当已删除。当前项目只提供空白表。

## 10–15分钟独立试用脚本

主持人准备：在localhost启动原型，确认所有任务均有演示标记；关闭开发面板的计时加速；准备下面空表。设置少动画/键盘由参与者选择。不要求安装扩展或提供真实浏览资料。

1. **0–1分钟，同意**：“我们在测试一种可选的休息和返回入口，不评估你的专注能力。可以用样例、跳题或随时停止。默认不录屏。你是否愿意我记录不含个人信息的操作观察？”未同意则只演示，不填研究表。
2. **1–3分钟，过去行为**：选访谈题1、4、5、6。只问最近一次具体经历，不引导“这个功能肯定有用”。
3. **3–4分钟，基线与自由选择**：先阅读样例任务，短暂切离后回来，说出下一步并按自己想法操作，记录直接Resume找回成本。再单独给出“如果现在有点想停下来，你接下来会怎么做”的情境，不说歇一下按钮的位置，允许直接返回、关界面或离开。记录未经提示的选择和理由；这只检查情境中的可发现性/偏好，不当自然使用率。
4. **4–7分钟，第一方案**：询问是否愿意比较研究方案，愿意才按分配的C或B进入，最大45秒；“你可以提前结束或随时停止”。拒绝则保留为负例并直接复盘，不从N删除。结束后不要提示Resume位置，观察其选择、压力和解释。
5. **7–10分钟，第二方案**：再次确认愿意体验后，保持同一样例内容和45秒上限试另一方案。不要说哪个更好；记录是否想继续停留和何时结束。主持人安排体验与自由选择分开记录。
6. **10–11分钟，D对照**：展示可以只暂存一句、直接返回，问刚才哪种情境会选它；不把假设偏好当真实采纳。
7. **11–14分钟，复盘**：哪一步多余？哪种最容易结束？如果不用工具会怎么做？愿意在下一次真实情境自己打开吗，为什么？若愿意，可计划另一次自愿试用，不能当场写成已经验证。
8. **14–15分钟，收尾**：展示重置样例，说明记录删除时间，允许要求不保留某条内容。记录退出本身，不做羞辱性评分。

键盘、无任务、归档、重开和多窗口等工程边界另由QA脚本测试；不把15分钟用户访谈塞满故障操作。

## 访谈后决策规则

首轮N至少5后，**分别为拟放行的同一个C或D候选**计算c/N（能独立指出下一步）与v/N（能指出比直接Resume多出的具体价值）：至少80%和60%，且没有错绑/泄露/丢记录。不能将C的清晰度与D或B的价值评分拼成通过，也不能用B的结果放行C。N=5时分别是4人和3人，N=8时分别至少7人和5人。它们是工作放行阈值，不是总体效果检验；未体验该候选、跳题或退出记缺失，不当失败标签，也不能满足门槛。

- 用户愿意主动用且容易回来：只为胜出的最小C/D候选进入正式工程评审。
- B有趣但2人及以上想继续停留、反复延长或觉得更难返回：删除/收紧娱乐层，即使“喜欢”评分高。
- 多数更喜欢D或直接Resume：只做轻量返回入口或先优化Resume，取消完整休息路线。
- 不足5名、主要是引导下操作、负例无法解释：继续研究或停止，不宣称通过。

1人也可暴露严重数据/自主性问题；此类问题先暂停，不等待凑满人数。正式门槛见[09_RELEASE_GATES](09_RELEASE_GATES.md)。
