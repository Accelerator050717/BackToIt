# v0.2b 当前可交付什么、下一步放行什么

日期：2026-10-23（America/Los_Angeles）。对象：产品/设计/工程审阅者。**当前建议：交付独立ADHD-first研究原型与文档，优先验证Tiny Start；不合并v0.1正式扩展、不作医学效果宣传。Gate1未过，Gate2未开始。** 本轮招募/真人参与者为0。工程结果见[07报告](07_TEST_AND_SKILLS_REPORT.md)，不能用“测试全通过”代替用户价值判断。

| 结论                                                          | 证据与准确边界                                                                     |
| ------------------------------------------------------------- | ---------------------------------------------------------------------------------- |

| 旧v0.1有现场保存/恢复基础，但新帮助层需显式任务绑定与版本校验 | 本地代码审计，非真人收益结论；正式集成仍需事务合同与真实扩展测试                   |

| Tiny Start是一条值得优先验证的主线                            | 与已有下一步和现实启动直接相连；选择理由是问题匹配与验证成本，不是效果数据         |
| 点击/计时/拼接完成与真实动手不同                              | 测量定义；不能把界面事件直接算作专注、学习或改善                                   |

## 可交付与禁止当成完成的事项

可以在现有私库独立分支审阅：本轮定位、六困难地图、PRD、两阶段协议、决策、测试证据、合成数据独立原型与源码。旧Detour与2026-10-22结论仍保留对照。可在本机启动体验，不需要账户、诊断或真实任务资料。

不能据此做：将原型写入生产数据库/安装包、直接合并main、宣告v0.2正式上线、公开部署、宣称治疗/恢复脑功能/几秒提高专注、导入研究参与者真实任务、请求手机通知或屏幕使用权限。原型不是正式扩展，也不是医学效果证明。用户已授权本轮独立分支提交/推送到既有私库；该审阅推送不构成生产发布。

## 体验入口与建议走查

从仓库根目录按[新原型README](../../../prototypes/adhd-first/README.md)启动，入口为本机 `http://127.0.0.1:4178/`；开发服务器只在运行时可用，不是公共托管链接。旧原型端口4174与新入口分开。清洁克隆先安装锁定依赖，不能把本机已有构建/浏览器缓存当作仓库自带。

建议先体验首页与“开始不了”，不要先从拼图判断产品价值：

1. 看演示任务与**保存的下一步**，先直接“接着做”，观察它如何说明只是演示返回意图。
2. 回到首页进入“我卡住了 → 开始不了”，读取本地建议、修改它，分别选择不计时小动作与自愿30秒，辨别“按下开始”与真的动手。
3. 体验“想刷点别的”，看固定三片如何逐步成形；第三片、提前结束、时间上限都应回同一任务卡，没有下一局推荐。
4. 试“我真的累了”和“先放这里”：离开页面再回来；一句可跳过的暂存不应变成新任务或强制计时。
5. 通过研究场景控制器/第二窗口改下一步、归档、删除；尝试返回，应看到冲突/限制，不能错绑另一演示任务。切语言与减少动画后重复关键路径。

演示使用合成任务。不要输入私人资料、真实诊断或工作机密。主持研究时也不要求参与者透露这些内容。

## Gate 0：研究交付的工程与范围门槛

门槛：新原型完整路径、真实有界状态机、时间恢复、任务版本保护、双语/键盘/reduced motion、规定视口、存储失败/损坏、网络与数据隔离；v0.1受保护源码/schema/权限/产物指纹不变，必要构建/核心回归有本轮日志；敏感文件排除后才推私库分支。

实际通过项、初次失败与修复、命令/截图/未验项只以[07报告](07_TEST_AND_SKILLS_REPORT.md)及其证据为准。本文件不复制测试数字，避免历史105/6、旧原型18/8与本轮新执行混淆。若有未满足P0，不宣称Gate0全过；保留可复现问题和已工作的体验。

Gate0只证明可做受控研究，不能批准正式发布。自动可访问性/布局检查也不等于真实屏幕阅读器、原生缩放或真人接受。

## Gate 1：5–8名成人探索，当前未过

按[04研究协议](04_EXPERIMENT_AND_INTERVIEW.md)执行10–20分钟自愿会话，轮换顺序，不强迫全路径。比较同一个人不同意图下的直接Resume、Tiny Start、Tiny Spark、Quiet与Parking。允许拒绝、提前退出与只选一个按钮；负面意见是结果。

必须回答：能否独立发现入口、说清保存下一步与建议的区别、找到同一任务的下一步；帮助是否多此一举；是否出现想继续玩、被催促、填写/选择负担。报告全体与每路径实际暴露/选择的分母、退出和缺失，不能只挑喜欢者。预先规则是产品工作阈值，不是统计显著性或医学结论。

暂不将旧v0.2的C/D阈值机械转给新Tiny Start。以新协议的可理解性、负担和明确价值/否定理由逐路径判断；至少5名同意记录并开始自由观察的成人后才归纳探索；拒绝候选与退出仍计入N1。候选不足5人被提供或大量缺失只能称为线索；本阶段本身不构成真实价值验证。对错误任务暴露、严重负担或无法退出应立即停测修复，不等待人数达标。

## Gate 2：真实时段需求探针，当前未开始

编号说明：本轮把两阶段研究分别列为 Gate1/2，正式工程另列 Gate3；旧v0.2的Gate2指正式工程。旧记录不改名，审阅时以版本与阶段内容为准。

只在自愿基础上做一次真实学习/工作时段。没有摄像/录屏，不追踪B站/抖音，不问药物/诊断证明/治疗史，不自动分析行为。区分是否自行想起、是否主动打开、是否结束帮助、是否尝试第一个现实动作，以及谁提醒了打开。

当前原型仍只用合成任务。参与者把真实下一步留在自己纸上或已有本地工具，不把内容导入原型或发给主持人。**本阶段能探查真实需要与自发使用，不能验证生产绑定卡的收益或真正浏览器恢复能力。** 若要研究真实任务卡，须另行批准具备数据控制的本地集成研究；不借阶段2绕过此轮数据边界。

未打开、忘记工具、选择直接回任务、选择休息或中途不用，均进入记录；自述不能改写成观察。小样本只做描述性判断，不编改善百分比，更不推论临床或持续专注效果。

## Gate 3：未来正式扩展工程放行，尚未申请

只有方向得到足够需求证据、隐私范围单独批准后，才设计正式扩展最小实现。最低条件：

- 保存未提交草稿成功后，绑定持久taskId/revision；同一仓库事务校验状态/版本并激活，成功后才开资料。修改/归档/删除竞态失败时零开页。
- 不扩大权限解决触达；明确会话最小数据、清空传播、共享设备风险、浏览器重启与无存储边界。禁止删除后旧会话复活。
- 在真实扩展worker/侧栏与IndexedDB做集成E2E、双窗口竞态/故障、旧备份兼容与无原型污染检查；有可回退构建。
- 真人无障碍与实际使用负担走查，文案只承诺已证实能力；原型数据不得迁移到真实任务库。

正式手机端、通知、云同步和AI各自需要新的需求/数据/权限决定；不包含在Gate3的默认授权中。

## 根据结果收窄路线，而不是坚持原型

| 下一轮发现                                       | 产品动作                                                   |
| ------------------------------------------------ | ---------------------------------------------------------- |
| Tiny Start帮人说清并尝试一小步，且额外操作可接受 | 优先设计最小本地集成与实际任务研究；先不扩长计划清单/AI    |
| Tiny Spark受欢迎但更难结束、使原任务更远         | 删除或默认隐藏该候选，不以喜欢/停留数据抵消返回摩擦        |
| Tiny Spark对少数意图有具体价值且容易停下         | 作为主动可关闭次级路径继续研究，不能替代直接Resume         |
| Quiet/Parking有价值、其他层增加负担              | 收窄到有价值的路径，保留旧对照和被否决理由                 |
| 直接Resume已经更好                               | 保持简单恢复核心；不为功能完整而强留帮助层                 |
| 真实想用时已在手机、不会回桌面                   | 先验证无私密数据的轻移动主动入口概念；不伪装手机监测/同步  |
| 各路径均无自发使用价值                           | 暂停新增功能，回到使用情境与问题研究；不以更多原型继续背书 |

下一次最值得看的屏幕是 **首页保存的下一步 → 我卡住了 → 开始不了的一项建议**。它最直接暴露产品是否真的减少启动摩擦；拼接则检验我们能否兼顾一点趣味与自然结束。当前没有真人证据，因此可交付一套可体验、可否定的产品假设，不能交付“ADHD已改善”的结论。
