# ADHD 日常困难、机制与证据边界

研究日期：2026-10-23（America/Los_Angeles）。状态：案头研究与已有实现核对；本轮真人参与者为 0。本文把执行功能困难转成待验证的产品行为，不提供诊断、治疗或药物建议。

BackToIt 要减少的是「下一步已经知道，重新动起来仍很费劲」时的操作负担。ADHD-first 在这里意味着：保留用户自己的任务线索，允许不同刺激需要，少作选择，随时退出，对没有开始和决定休息都正常回应。功能数量、小游戏吸引力和停留时间不能代表这件事已经做到。

## 从研究到界面的约束

1. 先展示用户已经选择的任务与真正保存的下一步。直接 Resume 不经过状态问答，不要求计时，也不要求体验趣味互动。
2. 「开始不了」「想刷点别的」「真的累了」「突然想到别的事」表达需要，不给人分类；同一个人可在不同时间选择不同路径。没有自动 ADHD 模式。
3. 缺少下一步就明确显示缺少；本地建议标为建议，保留原文本。内容、版本、归档或删除发生变化时先处理冲突，不悄悄换目标。
4. 趣味要靠可感知的手感、三步闭合和可预期反馈，不能靠积分、输赢、稀缺、随机奖励或下一关。关闭趣味和减少动画都必须有效。
5. 结束是正常状态。用户没有返回、不愿再用或决定真的休息，记录为选择及其原因，不给失败分数。
6. 桌面原型不能看见手机，不能判断一个网页是否有用。研究只问用户愿意描述的经历，不读取站点、屏幕、手机、健康或身份资料。

两阶段脚本、分母与反例判断见 [04_EXPERIMENT_AND_INTERVIEW.md](04_EXPERIMENT_AND_INTERVIEW.md)。目前最值得投入观察的是 Tiny Start 与原始下一步之间的衔接；Tiny Spark 保留为可被否决的比较候选。这个排序来自降低额外组织负担的产品判断，仍是 H。
