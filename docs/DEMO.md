# 完整演示与人工验收

演示数据均为合成内容，不使用个人记录。无需模型或网络。

1. 安装正式包，点击工具栏接着来。首次页最多一屏说明，选「开始一件事」。
2. 创建「理解参数方程」，下一步先留空。恢复卡显示确定性本地提示。
3. 在一个普通资料页点击工具栏图标，然后从真正的侧边栏保存当前页。反馈必须在提交后显示，任务中出现标题和保存时间。
4. 在另一资料页的普通正文选择一句话，右键「保存选中内容到接着来」。检查摘录、URL和所属任务；重复保存同一 URL，资源合并且不同摘录保留。试一次撤销。
5. 给资料加一句用途并设为首要。通过「链接或笔记」写一条本地笔记。
6. 点「保存现场」：进度写「看完了 dy/dx 的推导」，卡点写「dx/dt 等于 0 时为什么单独讨论」，下一步写「回看例题 2，分别算 dx/dt 和 dy/dt」。
7. 点「保存并暂停」。关闭侧边栏、重开；再退出该测试浏览器、重开。三段记录与资料应在。
8. 保留一个无关标签页。恢复卡点「接着做」，仅首要网页打开或准确复用；无关页不得关闭、跳转或重排。展开选择更多资料时先看到打开数量。
9. 在「先放这里」写「之后查相机价格」。当前任务不变，可编辑、完成、删除或主动转为新任务。
10. 创建第二任务，第一个自动暂停。管理页搜索第一个任务标题或资源标题，查看历史快照；完成后可重新接着做。
11. 导出 JSON，再预览导入为新任务。原任务保留，导入任务用新 ID，关联仍正确。试损坏 JSON，必须显示错误且已有任务不变。
12. 切英文确认文案切换且用户记录未改写。关网络后再创建、记录、暂停、恢复、导出。

## Chrome 原生入口手工验收

以下检查涉及浏览器原生工具栏、系统右键或用户手势，自动化覆盖情况必须以测试报告为准：

- 点击真正工具栏图标，侧边栏打开；此动作本身不保存页面。
- 在侧边栏保存当前页成功后，切换另一个未经授权的网页，保存应提示重新授权。跨站导航再试，不能保存旧 URL。
- 用网页右键保存页面，选中普通正文后右键保存摘录；在 input/textarea/password/contenteditable 内操作不得捕获其内容。选区跨过表单也应拒绝。
- `chrome://extensions`、Chrome Web Store、扩展页不可注入时展示可理解提示，不绕过限制。
- 在 `chrome://extensions/shortcuts` 验证/调整 Ctrl+Shift+Y 与 Alt+Shift+S，没有抢占网页普通输入键。
- 授权本地 AI 的 Chrome 权限对话框只在主动开启时出现。拒绝也应保留全部普通功能；关闭后在扩展详情检查权限撤销。
- 在扩展 worker 检查页停止 service worker 后，重新执行保存，应唤醒并读回数据库。
- 键盘 Tab 顺序可达，Esc 关闭模态框并恢复焦点；200% 缩放主要功能仍可操作。屏幕阅读器需人工听读确认，不以 DOM 检查代替。
